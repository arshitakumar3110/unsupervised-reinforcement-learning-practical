# Unsupervised & Reinforcement Learning Practical

This repository contains a practical implementation of **Unsupervised Learning** and **Reinforcement Learning** using Python and Google Colab.

The practical focuses on understanding how machine learning can be applied to simple business problems such as **customer segmentation** and **delivery-route selection**.

## 📌 Contents

### Part A — Customer Segmentation Using K-Means

In this section, **K-Means Clustering** is used to divide customers into three groups based on:

* Monthly Spending
* App Visits

The practical includes:

1. Importing required Python libraries
2. Creating a customer dataset
3. Selecting features for clustering
4. Applying K-Means with `K = 3`
5. Visualizing customer groups
6. Viewing customers cluster by cluster
7. Interpreting clusters from a business perspective
8. Answering business-related questions

The clusters can be interpreted as different customer behaviour groups, such as:

* Premium Customers
* Medium-Value Customers
* Low-Engagement Customers

Possible business actions include loyalty rewards, personalized recommendations, and re-engagement campaigns.

---

### Part B — Introduction to Reinforcement Learning

This section introduces the basic concept of **Reinforcement Learning** through a delivery-route example.

A delivery company has two possible routes:

* Route A
* Route B

The system learns by following:

**Action → Reward → Learning from Result**

The practical explains:

* Agent
* Environment
* Action
* Reward
* Exploration
* Exploitation

It also demonstrates how average rewards can help a system prefer a route that has historically performed better.
